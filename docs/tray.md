# 트레이(메뉴 막대) 아이콘

telima는 창을 닫아도 계속 실행되고, 메뉴 막대(macOS) 또는 시스템 트레이(Linux)에 아이콘을 둔다.
아이콘 메뉴에서 프로필별 시작·중지·재시작, 창 열기, 새로고침, 종료를 할 수 있다.

## 동작

- 창을 닫아도 앱은 종료되지 않는다. 처음 닫을 때 한 번 안내 알림이 뜬다(실행할 때마다 한 번. 설정 저장소가 아직 없어 기억하지 않는다).
- 종료는 메뉴의 "telima 종료"로 한다.
- macOS에서 Dock 아이콘을 누르면 닫힌 창이 다시 열린다.
- 프로필 상태는 10초마다 다시 읽는다. 메뉴의 "새로고침"은 즉시 읽는다.
- 트레이를 띄울 수 없는 환경(아래 GNOME 항목 등)에서는 창을 닫으면 앱이 종료된다(Linux). macOS는 원래 창을 닫아도 앱이 남는다.
- 트레이 메뉴에서 시작·중지·재시작·새 프로필을 누르면 창이 닫혀 있어도 창을 다시 열어 그 안에서 실행한다. 진행 로그를 보여 주기 위해서다.
- 메뉴 항목의 "시작 중" 같은 표시는 트레이에서 보낸 명령일 때만 정확하다. 창에서 시작한 작업은 "처리 중"으로 보인다.

## macOS: 아이콘이 안 보일 때

- 메뉴 막대가 꽉 차면 새 아이콘은 "«" 뒤로 접힌다. "«"를 눌러 확인한다. 앱은 접힌 상태를 신뢰성 있게 알아낼 수 없다.
- 보이는 위치로 옮기려면 ⌘(Command) 키를 누른 채 아이콘을 끌어 다른 아이콘 사이로 옮긴다. 안 쓰는 아이콘을 ⌘ 끌어서 막대 밖으로 빼면 자리가 난다.
- 시스템 설정 → 제어 센터(또는 메뉴 막대) → "메뉴 막대에서 허용" 목록에 telima가 있으면 켜져 있는지 확인한다. macOS 버전에 따라 이름과 위치가 다르다.

## Linux: GNOME

GNOME은 기본으로 트레이를 지원하지 않는다. AppIndicator/KStatusNotifierItem 확장(예: "AppIndicator and KStatusNotifierItem Support")을 설치하고 켜야 아이콘이 보인다. 확장이 없으면 telima는 트레이 없이 실행되고 창을 닫으면 종료된다. KDE·Xfce 등 StatusNotifierItem을 지원하는 환경은 추가 설정이 필요 없다.

## 두 번 실행하면

단일 실행을 강제하지 않는다. telima를 두 번 실행하면 창과 트레이 아이콘이 둘 생긴다. 한쪽은 종료 메뉴로 끝낸다.

## 알려진 한계

- Linux 밝은 패널용(`-light`) 아이콘은 확인하지 못했다. 기본은 어두운 패널용이다.
- 알림은 macOS `osascript`, Linux `notify-send`로 보낸다. 없으면 알림 없이 지나간다.
