# 사용법 가이드 (v0.1.1)

할 일별 순서다. 따옴표 안의 문구는 화면에 나오는 그대로다. 각 기능의 세부 규칙은 [기능 명세](features.md)에 있다.

## 처음 실행

1. Colima 0.10.3 이상을 설치한다. Homebrew를 쓰면 `brew install colima`.
2. telima를 연다. macOS에서 서명되지 않은 앱이라 막히면 [README](../README.md#설치)의 방법으로 연다.
3. 화면 위쪽 배너를 확인한다.
   - "Colima가 설치되어 있지 않습니다.": 안내된 명령으로 설치한 뒤 앱을 다시 연다.
   - "Colima 업데이트 필요": `brew upgrade colima`로 올린 뒤 다시 연다.
   - "검증되지 않은 Colima 버전": 대부분 동작한다. "닫기"로 닫고 써도 된다.
4. 이미 만든 Colima 프로필이 있으면 왼쪽 "프로필" 목록에 바로 보인다. 없으면 "프로필이 없습니다."가 나온다.

## 프로필 만들기

1. 툴바의 "새 프로필"을 누른다. 프로필 드롭다운 맨 아래 "새 프로필…"이나 트레이 메뉴로도 열 수 있다.
2. "이름"을 적는다(예: dev). 영문 소문자, 숫자, `-`만 쓸 수 있고 32자까지다.
3. "CPU", "메모리", "디스크"를 −/+ 버튼으로 정한다.
4. "VM 종류"와 "마운트"를 고른다. macOS에서 x86 이미지를 돌리려면 VM 종류 vz에서 "Rosetta"를 켠다.
5. 호스트 폴더를 VM에 보이려면 "디렉터리"에서 "+ 추가"를 누르고 절대 경로를 적는다. 쓰기가 필요하면 "읽기·쓰기"로 둔다.
6. 호스트에서 VM에 IP로 닿아야 하면 "IP 주소"를, k3s가 필요하면 "Kubernetes"를 켠다. Kubernetes를 켜면 시작이 더 오래 걸린다.
7. "만들기"를 누른다. 프로필이 만들어지면서 바로 시작되고, 진행 화면에 "시작 단계"와 "시작 로그"가 나온다.

## 시작·중지

- 왼쪽 목록이나 툴바 드롭다운에서 프로필을 고르고 툴바의 "시작", "중지", "재시작"을 누른다. 지금 상태에서 할 수 있는 버튼만 보인다.
- 진행 화면에서 단계, 로그, 경과 시간을 본다. 끝나면 "실행 중" 또는 "중지됨"이 나오고 "닫기"로 닫는다.
- 시작을 멈추려면 "시작 취소"를 누른다. VM은 멈추고 만든 디스크는 남는다.
- 상태가 "오류"면 "시작", "재시작", "중지"가 모두 열린다. 하나씩 시도해 복구한다.

## 설정 바꾸기

1. 프로필을 고르고 "구성" 옆 "편집"을 누른다.
2. 값을 바꾸고 "저장"을 누른다. 이름과 VM 종류는 바꿀 수 없고 디스크는 늘리기만 된다.
3. 실행 중인 프로필이면 폼 아래에 "… 변경은 프로필을 재시작해야 적용됩니다."가 나온다. 저장 뒤 툴바의 "재시작"을 눌러야 적용된다.

## 트레이로 쓰기

- 창을 닫아도 telima는 메뉴 막대(macOS)나 시스템 트레이(Linux)에 남는다. 처음 닫을 때 안내 알림이 한 번 뜬다.
- 트레이 메뉴에서 프로필 이름에 마우스를 올리면 "시작", "중지", "재시작"이 나온다. 누르면 창이 열리고 창 안에서 진행된다.
- "창 열기"로 창을 다시 연다. macOS는 Dock 아이콘을 눌러도 된다.
- 끝내려면 "telima 종료"를 누른다. 창에 초점이 있으면 ⌘Q(Linux는 Ctrl+Q)도 된다.
- 메뉴 맨 위에 "오류: … — 창에서 보기"가 보이면 눌러서 창에서 내용을 확인한다.
- macOS에서 아이콘이 안 보이면 메뉴 막대의 "«"를 눌러 본다. 자세한 방법은 [tray.md](tray.md)에 있다.

## 컨테이너 로그 보기

1. 프로필이 실행 중인지 확인하고 "컨테이너" 탭을 연다.
2. 찾는 컨테이너가 많으면 "이름·이미지로 필터"에 적거나 "전체"·"실행"·"종료"로 거른다.
3. 행 오른쪽 더보기 메뉴에서 "로그 보기"를 누른다.
4. 새 줄을 계속 보려면 "따라가기"를 켜고, 지금까지의 로그만 보려면 끈다. 줄마다 시각을 보려면 "시각"을 켠다.
5. 특정 낱말이 든 줄만 보려면 "로그 검색"에 적는다. 대소문자는 구분하지 않는다.
6. Esc로 닫는다.

같은 메뉴의 "재시작", "삭제"로 컨테이너를 다시 시작하거나 지운다. 실행 중인 컨테이너를 지우면 강제로 중지한 뒤 지운다.

## 이미지·볼륨 정리

- 종료된 컨테이너: "컨테이너" 탭의 "종료된 N개 삭제". 실행 중인 컨테이너와 볼륨은 남는다.
- 이미지: "이미지" 탭의 "미사용 이미지 정리". 태그 없는 이미지만 지운다. 확인 창에서 개수와 크기를 보고 누른다.
- 볼륨: "볼륨" 탭의 "미사용 볼륨 정리". 어떤 컨테이너도 쓰지 않는 볼륨을 이름 있는 볼륨까지 지운다. 되돌릴 수 없다.
- Colima 캐시: 왼쪽 아래 "캐시 정리". 내려받아 둔 VM 이미지 같은 캐시만 지우고 프로필·컨테이너·볼륨은 그대로다.

## 프로필 삭제

1. 프로필을 고르고 "구성" 아래 "프로필 삭제"를 누른다. 시작·중지가 진행 중이면 누를 수 없다.
2. 이미지와 볼륨도 지우려면 "데이터 디스크도 삭제"를 켠다. 끄면 데이터 디스크가 남아 같은 이름으로 다시 만들 때 이어서 쓸 수 있다.
3. 확인 칸에 프로필 이름을 그대로 적는다.
4. 빨간 버튼("프로필 삭제" 또는 "볼륨 N개, … 삭제")을 누른다.

## 문제 해결

- "Colima VM 또는 Docker 엔진에 연결할 수 없습니다. 프로필이 실행 중인지 확인해 주세요.": 프로필을 시작한다. 실행 중인데도 나오면 "새로고침"을 누른다.
- "프로필이 중지되어 있습니다. 시작하면 컨테이너·이미지·볼륨을 볼 수 있습니다.": 컨테이너·이미지·볼륨 탭은 실행 중인 프로필에서만 보인다.
- "목록을 불러오지 못했습니다.": "다시 시도"를 누른다.
- "다른 작업이 진행 중입니다. 끝난 뒤 다시 시도해 주세요.": 같은 프로필의 작업이 끝날 때까지 기다린다.
- 시작이 실패하면 진행 화면의 로그에서 ERRO 줄을 확인한다. 트레이에는 "오류: <프로필> 시작 실패 — 창에서 보기"가 남는다.
- 트레이 아이콘이 둘이면 telima가 두 번 실행된 것이다. 하나를 "telima 종료"로 끝낸다.
- Linux에서 창을 닫았더니 앱이 끝났다면 트레이 호스트가 없는 환경이다. GNOME은 AppIndicator 확장을 켠다.
- macOS에서 "손상되었기 때문에 열 수 없습니다" 같은 경고가 나오면 `xattr -dr com.apple.quarantine /Applications/telima.app`을 실행한다.
